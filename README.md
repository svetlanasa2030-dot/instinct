# Auto Message Sender

Программа для автоматической отправки разных сообщений в выбранную точку экрана.

## Возможности

- выбор точки экрана мышкой;
- несколько разных сообщений;
- отдельный интервал для каждого сообщения;
- по умолчанию: 48 минут, 78 минут (1 ч 18 мин), 98 минут (1 ч 38 мин);
- автоматический клик, вставка сообщения и Enter;
- кнопки запуска и остановки;
- F8 для остановки.

## Установка зависимостей

```bash
pip install pyautogui pyperclip
```

## Запуск

```bash
python auto_message_sender.py
```

## Создание EXE

```bash
pip install pyinstaller
pyinstaller --onefile --windowed auto_message_sender.py
```

Готовый EXE появится в папке `dist`.

Используйте автоматизацию только там, где она разрешена правилами соответствующего приложения или сервиса.
